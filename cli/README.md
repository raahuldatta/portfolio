# raahuldatta

Interactive CLI portfolio for Raahul Datta — Backend, Cloud & GenAI Engineer.

## Usage

```bash
npx raahuldatta
```

No install required. Pick a section from the menu — About, Work, Stack, Experience, Building now, Contact — and it prints straight to your terminal. Keep picking sections until you're done; select **Exit** (or Ctrl+C) to quit.

## Why

Same content as [raahuldatta.vercel.app](https://raahuldatta.vercel.app), for anyone who'd rather stay in a terminal.
