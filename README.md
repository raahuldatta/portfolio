## 🤖 AI / ML Focus

My current AI engineering work focuses less on simply calling LLM APIs and more on designing **systems around the models**.

### Retrieval-Augmented Generation

Building pipelines that retrieve relevant information before generation so responses can be grounded in external evidence.

### Agentic Systems

Designing multi-step AI workflows capable of reasoning across tasks, calling tools, retrieving information, and coordinating specialized agents.

### Multi-Model Arbitration

Exploring architectures where multiple language models independently answer a query and an arbitration layer evaluates or synthesizes their outputs.

### AI Guardrails

Building validation layers around generated outputs using:

* Schema validation
* Hallucination detection
* Role-based access control
* Human approval gates
* Structured outputs

### AI Observability

Exploring how logs, traces, retrieval context, intermediate reasoning steps, and model outputs can be monitored in production AI systems.

### On-Device AI

Experimenting with local inference and RAG architectures where sensitive information never leaves the user's machine.

## 🚀 Featured Projects

### 🧠 Ember — AI Incident Response Engineer

An AI-powered incident investigation system designed to analyze production failures end-to-end.

Ember aggregates alerts, logs, traces, deployment information, and historical incidents to identify potential root causes and generate structured remediation reports.

**Stack**

`Python` `FastAPI` `LangGraph` `PostgreSQL` `OpenTelemetry` `LLM Orchestration`

**Key ideas**

* Multi-agent incident investigation
* Log and trace analysis
* Historical incident retrieval
* Deployment correlation
* Structured remediation reports
* Human-in-the-loop approval

**Repository**

https://github.com/raahuldatta/Ember

---

### 🔐 Vaultmind — On-Device RAG Knowledge Assistant

A privacy-first RAG assistant designed to understand a developer's own codebase and documentation.

Instead of sending proprietary source code to external AI APIs, Vaultmind performs retrieval and inference locally.

Built for the **Snapdragon AI Lab Build & Present Challenge**.

**Core concepts**

* On-device RAG
* Local embeddings
* NPU-accelerated inference
* Private codebase Q&A
* Zero-data-leaving-device architecture

**Status:** 🚧 In Development

---

### 🤖 Verdikt — LLM Arbitration System

A multi-model AI architecture that sends queries to multiple LLM providers and evaluates their outputs before producing a final response.

The goal is to reduce dependence on a single model and experiment with cross-model verification.

**Core concepts**

* Multi-LLM routing
* Parallel model execution
* Model judging
* Response arbitration
* Provider-isolated API handling

**Status:** 🚧 In Development

---

### 🛡️ Quardian — Secure Text-to-SQL System

A secure natural-language-to-SQL application designed around guardrails rather than unrestricted query generation.

**Core concepts**

* Natural language → SQL
* Schema validation
* Hallucination detection
* Role-based access control
* Query logging
* Performance analytics

**Status:** 🚧 In Development

## 🚀 Getting Started

### 1. Prerequisites

Make sure you have:

```text
Node.js 18+
npm / pnpm / yarn / bun
```

### 2. Clone the repository

```bash
git clone https://github.com/raahuldatta/<repo-name>.git
cd <repo-name>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### 5. Production build

```bash
npm run build
npm start
```
